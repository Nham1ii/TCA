# TCA

Jogo culinário
combina ingredientes digitados pelo usuário e seu modo de preparo para obter um prato

Possui receitas ja cadastradas inicialmente, sendo feitas na funçao 'preparar'
Pode cadastrar novas receitas no cardapio, podendo ser preparadas depois pelo usuario na funçao 'novoPrato'

Lista do cardápio é exibida no console, entrada de ingredientes e modo de preparo é através de prompts
